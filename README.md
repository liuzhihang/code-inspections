## 支持规则

### Concurrent

| 是否支持 |                                     规则名称                                     | 错误级别  |
|:----:|:----------------------------------------------------------------------------:|:-----:|
|  √   | 【强制】自定义的 ThreadLocal 变量必须回收，尤其是在使用线程池时，因为线程经常被复用。否则可能会影响后续业务逻辑，并导致内存泄漏等意外问题。 | Error |
